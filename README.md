# Nautical Dream

A premium, static-first boating lifestyle and affiliate publishing website.

## Included

- Responsive cinematic homepage
- Destinations, gear, marine weather, journal, about and contact pages
- Buying-guide template for affiliate content
- Privacy, affiliate and editorial disclosure page
- Newsletter signup interaction
- SEO-friendly titles and descriptions

## Deploy

This is a static website and can be deployed directly with GitHub Pages, Cloudflare Pages, Netlify, Vercel or GoDaddy hosting.

### GitHub Pages

Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
